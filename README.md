# mi-urba-corpus

Corpus sintéticos de quejas vecinales en español y sus extracciones de referencia.

## Datasets

| Carpeta | Contenido |
|---|---|
| [`dataset/final_10k/`](dataset/final_10k/) | 10.983 quejas con su extracción de referencia (ground truth) |
| [`dataset/iterations/`](dataset/iterations/) | tres corpus anteriores, sin auditar: `5k` (3.897), `20k` (20.000) y `50k` (50.000) |
